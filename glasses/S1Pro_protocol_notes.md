캡처: 2026-11-27 00:47:50 ~ 00:53:50, 안드로이드 btsnoop_hci.log
기기 이름: `S1Pro-1867` (주소 C1:32:05:00:18:67)

## 연결 구조
| 연결 | 용도 |
|---|---|
| 클래식 블루투스 A2DP (PSM 0x19) | 휴대폰 → 안경 스피커 소리 (음악, ChatGPT 음성) |
| 클래식 RFCOMM (PSM 0x03, HFP 추정) | 통화/마이크 |
| 클래식 AVRCP (PSM 0x17) | 재생/정지 버튼 |
| BLE GATT | Genimiro 앱 전용 명령 채널 |

## BLE 명령 채널
- 앱 → 안경: 핸들 `0x000C`에 Write Request
- 안경 → 앱: 핸들 `0x000E` Notify (CCCD 0x000F, 0x0012에 `01 00` 써서 켬)
- Android에서는 `BluetoothGattCharacteristic.getInstanceId()`가 보통 이 핸들 값과 같음
- 서비스 UUID는 캡처에 없음(앱이 캐시 사용) → nRF Connect로 확인 필요

### 패킷 형식
```
보내기:  AB 55 00 LEN CMD [DATA...] CHK
받기:    AC 55 00 LEN CMD [DATA...] CHK
LEN = CMD + DATA + CHK 바이트 수
CHK = (CMD + DATA 바이트 합) & 0xFF
```

### 확인된 명령
| CMD | 보낸 예 | 의미(추정) | 근거 |
|---|---|---|---|
| 0x59 | `AB 55 00 08 59 1A 0B 1B 00 30 0A D3` | 시간 맞추기 (26-11-27 00:48:10) | 값이 캡처 시각과 일치 |
| 0x22 | `AB 55 00 03 22 30 52` | **사진 찍기** | 00:48:16 전송, 사용자가 12:48 사진 촬영 |
| 0x42 (안경→앱) | `AC 55 00 04 42 00 01 43` | 촬영 완료 알림 (촬영 번호 1, 2…) | 촬영 몇 초 뒤 도착 |
| 0x23 / 0x24 | `AB 55 00 03 23 00 23`, `...24 00 24` | AI 인식 시작 / AI용 촬영 | 00:48:47~53, 사용자 AI 기능 12:48:49 |
| 0x97 / 0x51 (안경→앱) | `AC 55 00 03 97 01 98`, `AC 55 00 03 51 00 51` | 음성 입력 시작 이벤트 | 직후 음성 데이터 시작 |
| 0x56 | `AB 55 00 03 56 00 56` | 음성 스트림 받기 시작/종료 | 앞뒤로 0x46 데이터 |
| 0x46 (안경→앱) | 46바이트 패킷 1,615개 | 안경 마이크 음성 데이터 (코덱 미확인, Opus 아님) | 약 32개/초 |
| 0x17 | `AB 55 00 03 17 00 17` → `AC 55 00 05 17 34 37 01 83` | 상태/배터리 조회 | 주기적 반복 |
| 0x64 | `AB 55 00 02 64 64` → `... 64 54 6B 31 00 30 31 30 37 1C` | 기기 정보 ("Tk1", "0107") | 연결 직후 |
| 0x48, 0x95, 0x55, 0x45 | | 연결 초기 설정값 조회 | 연결 직후 |
