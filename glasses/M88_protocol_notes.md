## 확인된 명령 (0x57FF / 33F5)
`TT 00 01 00 01 00 01 00 VV` + 0 채움 (20바이트)
| 보낸 값 | Genimiro 로그 | 의미 |
|---|---|---|
| `0a 00 01 00 01 00 01 00 02` | setDeviceCmd type=2 → 파일 수 3 | **사진 찍기** |
| `0a … 03` / `0a … 04` | type=3 / 4 | 동영상 시작 / 끝 |
| `0a … 0b` / `0a … 0c` | type=11 / 12 | 녹음 시작 / 끝 |
| `01 … 02`, `08 … 01` | AI 시작 응답 | AI 세션 시작 |
| `08 … 00`, `05 … 00` | | AI 세션 종료 |

## 안경 → 앱 이벤트
| 받은 값 | 의미 |
|---|---|
| 0x26: `01 00 01 00 01 00 01 00 01` | **안경 AI 버튼 (onGetAiAction state=1)** |
| 0x26: `0a 00 01 00 01 00 01 00 VV` | 명령 확인 |
| 0x26: `02 [seq 4B] [len 2B LE] 00 00 data…` | AI 음성 데이터 (약 0.4초마다 350~500바이트) |
| 0x0C: `54 06 NN` | 안경 저장 파일 수 NN |
| 0x0C: `54 12 SS` | 녹화/녹음 상태 |
| 0x0C: `0b PP` | 배터리 PP% (0x64=100) |
